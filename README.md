## 📈 ترتيب التمارين (من الأبسط للأعقد)

**Week 1:**
1. **Book** — أساسيات الكلاسات والـ Fields والـ Methods.
2. **Student** — Encapsulation حقيقية، Validation، Constructor Overloading.
3. **Fraction & Shapes** — Operator Overloading، Inheritance متعدد المستويات، Polymorphism، Abstract Classes.

**Week 2:**
1. **EF Core** — التعامل مع قواعد البيانات بـ Code First و Database First.
2. **LINQ Exercises** — أهم الـ Operators في الاستعلام على البيانات.
3. **Delegates** — تمرير Methods كـ Parameters، وأنواع الـ Delegates الجاهزة في .NET.
